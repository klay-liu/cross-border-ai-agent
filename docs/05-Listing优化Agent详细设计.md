**版本**: v1.0

**优先级**: P1 — Phase 1

## 一、Agent 定位

Amazon 产品页面（Listing）是转化的最后一公里。好的 Listing 直接决定：
- 搜索排名（关键词覆盖度）
- 点击率（标题吸引力）
- 转化率（五点描述说服力）
- 客单价（A+ 内容品牌溢价）

```
传统做法:
人工参考竞品 → 凭感觉写文案 → 上线后凭经验修改

Agent 做法:
分析 Top10 竞品 Listing → 挖掘差评痛点反向优化 → 自动生成高转化文案
→ 多语言本地化 → 持续 A/B 测试迭代
```

## 二、核心能力

| 能力 | 说明 |
|------|------|
| **竞品 Listing 分析** | 拆解 Top10 竞品的标题结构、关键词布局、卖点提炼 |
| **标题生成** | 基于关键词+卖点生成多个候选标题，符合 Amazon 规范 |
| **五点描述生成** | 基于差评痛点反向包装卖点，突出差异化 |
| **产品描述/A+ 内容** | 生成品牌故事、场景化描述、技术参数展示 |
| **关键词优化** | 提取高相关关键词，嵌入标题和后台搜索词 |
| **多语言本地化** | 英/德/日 Listing 翻译，保持营销力 |

## 四、Amazon Listing 规范约束

### 标题规范
- 最大长度: 200字符（建议控制在150以内）
- 格式: `品牌名 + 核心关键词 + 规格/材质 + 数量 + 使用场景`
- 禁止: 全大写、促销语（"Sale", "Best"）、主观形容词
- 首字母大写（介词/冠词除外）

### 五点描述规范 (Bullet Points)
- 共 5 条，每条建议 150-250 字符
- 结构: `【卖点标题】+ 具体描述`
- 第1条: 核心差异化卖点
- 第2-3条: 功能/材质/品质
- 第4条: 使用场景/兼容性
- 第5条: 售后保障/包装内容

### 后台搜索词 (Search Terms)
- 最大 250 字节
- 不重复标题中已有的词
- 包含拼写变体、同义词、相关搜索词

## 五、Prompt 设计

### 竞品 Listing 分析 Prompt

```
分析以下 {n} 个竞品的 Amazon Listing，提取共性模式和差异化机会。

竞品 Listing 数据:
{competitor_listings}

请分析:
1. 标题结构: 各竞品标题的关键词布局模式
2. 高频关键词: 出现在多个竞品标题中的关键词（按频次排序）
3. 卖点分析: 五点描述中最常见的卖点主题
4. 缺失卖点: 竞品普遍没有提到但买家关心的点（结合差评）
5. 定价与规格: 竞品的规格-价格对应关系
```

### Listing 生成 Prompt

```
基于以下信息，为 Amazon US 产品生成高转化 Listing。

产品信息:
- 产品: {product_name}
- 品牌: {brand}
- 材质: {material}
- 规格: {specifications}
- 包装内容: {package_contents}
- 目标售价: ${price}

竞品分析结论:
- 高频关键词: {top_keywords}
- 竞品缺失卖点: {missing_selling_points}
- 买家核心痛点: {pain_points}

生成要求:
1. 标题 (3个候选):
   - 长度≤150字符
   - 格式: 品牌 + 核心词 + 材质/规格 + 数量 + 场景
   - 嵌入 Top 5 高频关键词
   - 首字母大写

2. 五点描述:
   - 第1条: 核心差异化（解决竞品痛点）
   - 第2条: 材质/品质优势
   - 第3条: 功能/规格完整性
   - 第4条: 使用场景/兼容性
   - 第5条: 包装内容 + 售后承诺
   - 每条 150-250 字符

3. 产品描述 (200-300词):
   - 场景化开头
   - 技术参数列表
   - 品牌信任背书

4. 后台搜索词 (≤250字节):
   - 不重复标题已有词
   - 包含同义词和拼写变体

输出 JSON 格式。
```

## 六、关键词优化策略

```
┌─────────────────────────────────────────┐
│           关键词金字塔                    │
│                                         │
│              ┌─────┐                    │
│             /  Top  \    ← 标题         │
│            / 3-5 核心 \   (高搜索量)     │
│           /───────────\                 │
│          /  Mid 10-15  \  ← 五点描述     │
│         /   中频长尾词   \  (中搜索量)    │
│        /─────────────────\              │
│       /   Long Tail 20+   \ ← 后台词    │
│      /    低频精准长尾词     \ (长尾)     │
│     /─────────────────────────\         │
└─────────────────────────────────────────┘
```
